# 目录图格式

入口 /approved/catalog。相对 @id 按当前响应地址解析；词汇固定为 Asset、Distribution、Grant，字段详见 fixtures。资产页中 distribution/grant 是关联链接，Grant 的 purposes、regions、expires_at 是远端声明，不能直接代替本地授权审批。空白节点标识只在文档内部有意义。/approved/conflict 返回同 ID 异文，/approved/redirect 跳到范围外。返回 404 表示当前无法获取，不能推导本地授权撤回。

运行 python demo_support/source.py --port 8787 可启动回环来源；运行 python demo_support/check.py 检查样本和故障开关。来源仅产生输入，不调用业务导入。

资产节点的 asset_id、kind、owner、columns 对应本地资产字段，title 作为说明；URI 身份另存来源证据。授权节点 grant_id、purposes、regions、rights、valid_from、obligations、columns、max_depth、allow_derivatives 对应本地策略，expires_at 对应 valid_until。字段缺失不补成宽松默认策略，允许在审查阶段补齐并记录人工值来源。
